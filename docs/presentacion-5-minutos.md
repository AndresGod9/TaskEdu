# Guion para la exposicion de cinco minutos

## 1. Presentacion del problema (40 segundos)

TaskEdu nacio de una necesidad comun entre los estudiantes: tener las actividades academicas organizadas, recordar las fechas de entrega y distinguir lo pendiente de lo que ya se termino. La idea del proyecto es ofrecer una aplicacion sencilla para manejar esas tareas desde el navegador.

## 2. Que construimos (1 minuto)

La primera version permite registrar una tarea con titulo, asignatura y fecha de entrega. Tambien permite consultar la lista completa, ver el estado de cada actividad, marcarla como terminada y filtrar entre todas, pendientes y terminadas. Los datos se conservan en el mismo navegador, incluso despues de actualizar la pagina.

## 3. Como nos organizamos (1 minuto)

Usamos Trello para organizar el backlog y mover las tarjetas entre Product Backlog, Sprint Backlog, En desarrollo, Revision de codigo, Pruebas y Terminado. En GitHub guardamos el codigo y trabajamos con ramas por historia para poder revisar los cambios antes de integrarlos. Los responsables y las fechas que aparecen en el tablero corresponden a los acuerdos reales de nuestro CIPA.

## 4. Pruebas y calidad (1 minuto)

Preparamos pruebas para validar el registro de tareas, impedir un titulo vacio, comprobar el cambio de estado y revisar los filtros. Tambien tenemos pruebas de integracion y aceptacion sobre el flujo principal. GitHub Actions ejecuta automaticamente la suite de pruebas cuando subimos cambios o abrimos una solicitud de cambio. En la presentacion mostraremos el resultado real de la ejecucion.

## 5. Resultado y retrospectiva (1 minuto)

Con esta versión entregamos un producto mínimo viable para organizar tareas académicas. Entre los aprendizajes del equipo están el uso de Git y GitHub para controlar los cambios, la revisión del código mediante Pull Requests y la ejecución de pruebas automatizadas.

Una dificultad fue aprender a trabajar con ramas y revisar los cambios antes de integrarlos. Para el siguiente sprint proponemos comprobar los criterios de aceptación y adjuntar las evidencias antes de mover cada tarjeta a Terminado.

## 6. Cierre (20 segundos)

En conclusion, Trello nos ayuda a organizar el trabajo, Git y GitHub permiten mantener el historial y revisar el codigo, y las pruebas automaticas ayudan a detectar errores antes de integrar cambios. TaskEdu es una primera version que se puede ampliar en futuros sprints.
