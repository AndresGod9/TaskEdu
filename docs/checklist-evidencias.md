## Como comprobar la integracion continua

1. Sube el proyecto a GitHub en la rama `main`.
2. Abre la pestana **Actions** del repositorio.
3. Entra en la ejecucion llamada **Pruebas TaskEdu**.
4. Si la ejecucion termina en verde, captura la pantalla donde se vea el nombre del flujo y el resultado exitoso. Si falla, abre el paso con error, corrigelo y vuelve a subir los cambios.
